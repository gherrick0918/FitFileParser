# FitFileParser

Accept a `.fit` activity file from Garmin or other devices and export organized
activity information as letter-size PNG pages suitable for uploading to coaching
platforms.

## Supported activity types

- Running (outdoor and treadmill)
- Cycling
- Any sport recorded by a Garmin or FIT-compatible device

## Requirements

- [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9)

## Build

```bash
dotnet build FitFileParser.slnx
```

## Usage

```bash
dotnet run --project src/FitFileParser -- <activity.fit> [--output <dir>]
```

**Example:**

```bash
dotnet run --project src/FitFileParser -- outdoor-run.fit --output run-report/
```

This produces one or more letter-size (8.5 × 11 in, 150 DPI) PNG files in the
`run-report/` directory.

## Report contents

Each report includes:

| Section | Fields |
|---|---|
| **Overview** | Sport, date, total/moving time, distance (mi), pace (/mi), avg/max speed, avg/max HR, cadence, calories/fat calories, avg/NP power, training effect, anaerobic TE, TSS, intensity factor, work, strides, ascent/descent, altitude and temperature ranges |
| **Lap table** | Lap number, time, distance (mi), pace (/mi), avg HR, max HR, avg power, normalized power, ascent, descent |

## Project structure

```
FitFileParser/
├── src/
│   └── FitFileParser/
│       ├── Program.cs          # CLI entry point
│       ├── Models/             # Normalized activity and lap models

├── tests/

├── samples/                    # Sanitized sample .fit files

```

## Run tests

```bash
dotnet test FitFileParser.slnx
```

## Not supported yet

- Maps and route visualization
- Charts (HR, pace, power over time)
- Strength / indoor-cycling workouts
- Multi-sport / triathlon transition sessions
- Developer-defined FIT fields
- Output formats other than PNG

## Privacy

FIT files can contain GPS coordinates, precise timestamps, and health-related
metrics such as heart rate and power output. FitFileParser processes files
locally; no data is uploaded to any external service.

When sharing reports generated by this tool, be aware that activity date,
duration, and performance data are visible in the output images.
